# P1174 打砖块

[题目传送门](https://www.luogu.com.cn/problem/P1174)

## 闲话

看题解最迷糊的一集。

## 思路

首先可以发现，除了子弹随意分配都可以打掉所有砖块的情况下，最后打掉的一定是 `N` 砖块。

考虑反证，如果最后打掉 `Y` 砖块，那么一定还有多余的子弹。

也就是说，**某一个 `N` 砖块不一定是最后一个打掉的，但是某一个 `Y` 砖块一定不是最后一个打掉的**。

其次容易想到对每一列考虑，对每一列「最后一发子弹」的类型进行分类讨论。

设 $s_{i,j,0/1}$ 表示对于第 $i$ 列，使用 $j$ 发子弹，这一列使用/不使用「最后一发子弹」，这一列的最大分数。

有一个发现：由于 $s_{i,j,1}$ 的定义，使得它可以打 `Y` 砖块，所以 $s_{i,j,1}\ge s_{i,j,0}$​。

或者也可以理解为 $s_{i,j,0}$ 所用的子弹不是从下往上连续地打的。

而且显然这个 $j$ 是可以通过模拟从下往上打这个过程求出来的。

于是设当前枚举到了第 $l$ 行：如果当前是 `Y` 砖块，这个砖块一定不是最后一个打掉的，$s_{i,j,1}=s_{i,j-1,1}+a_{l,i}$​；

如果当前是 `N` 砖块，两种都有可能，$s_{i,j,0}=s_{i,j,1}=s_{i,j-1,1}+a_{l,i}$。至于为什么从 $s_{i,j-1}$ 转移，是因为 $s_{i,j,1}\ge s_{i,j,0}$。

但是接下来会出现一种情况，这里不妨用样例来说明：

```
3 4 2
9 N 5 N 1 N 8 N
5 N 5 Y 5 N 5 N
6 N 2 N 4 N 3 N
```

通过模拟会发现，最优解是这样的：先打 `2 N`，再打 `5 Y`，最后打 `6 N`，答案是 `13`。

但是如果变一种顺序呢？

这样，先打 `6 N`，再打 `2 N`。这时候想要打 `5 Y`，但是子弹都用完了，所以这样是不可以的。

于是发现这样一列一列地转移还是有后效性的。

怎么解决？

发现问题出在“想要打一个 `Y` 砖块却发现此时恰好没子弹”的情况上。

根据前面的结论“最后打掉的一定是 `N` 砖块”，可以钦定一种转移顺序，先将用「最后一发子弹」的那一列确定，由于这时候**确保了打到那一列前有子弹**，剩下的列随便转移。

设 $f_{i,j,0/1}$ 表示对于第 $i$ 列，使用 $j$ 发子弹，$[1,i]$ 列使用/不使用「最后一发子弹」，$[1,i]$​ 列的最大分数，当前列要用 $l$ 发子弹。

如果 $[1,i]$ 列不使用，$f_{i,j,1}=f_{i-1,j-l,1}+s_{i,l,1}$。

如果 $[1,i]$ 列使用，分为两种情况：

- 第 $i$ 列使用，$f_{i,j,0}=f_{i-1,j-l,1}+s_{i,l,0}$。
- 第 $i$ 列不使用，即 $[1,i-1]$ 列中某一列使用，$f_{i,j,0}=f_{i-1,j-l,0}+s_{i,l,1}$。

## 代码

```cpp
#include <bits/stdc++.h>
// #define int long long
using namespace std;
typedef long long LL;
const int N = 2e2 + 2;
const int M = 1e2 + 2;
const int MOD = 19650827;
const int INF = 0x3f3f3f3f;
const LL LINF = 0x3f3f3f3f3f3f3f3f;
int n, m, k, a[N][N], sumn[N][N], sumy[N][N], f[N][N][2], s[N][N];

void Checkmax(int &x, int y) {
    x = max(x, y);
}

signed main() {
    // freopen("rfrt.in", "r", stdin);
    // freopen("rfrt.out", "w", stdout);
    scanf("%d%d%d", &n, &m, &k);
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            char ch;
            scanf("%d", &a[i][j]);
            cin >> ch;
            s[i][j] = (ch == 'Y' ? 1 : 0);
        }
    }
    for (int i = 1; i <= m; i++) {
        int tot = 0;
        for (int j = n; j >= 1; j--) {
            if (s[j][i]) {
                sumy[i][tot] += a[j][i];
            } else {
                tot++;
                sumn[i][tot] = sumy[i][tot] = sumy[i][tot - 1] + a[j][i];
            }
        }
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 0; j <= k; j++) {
            for (int l = 0; l <= min(j, n); l++) {
                Checkmax(f[i][j][1], f[i - 1][j - l][1] + sumy[i][l]);
                if (l != j) {
                    Checkmax(f[i][j][0], f[i - 1][j - l][0] + sumy[i][l]);
                }
                if (l != 0) {
                    Checkmax(f[i][j][0], f[i - 1][j - l][1] + sumn[i][l]);
                }
            }
        }
    }
    printf("%d", f[m][k][0]);
    return 0;
}
```
